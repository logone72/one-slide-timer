# 원 슬라이드 타이머

모바일에서 한 번의 제스처로 병렬 타이머를 만들고 조정하는 웹앱.

## 로컬 실행

```bash
nvm use
npm install
npm run dev
```

## 검증

```bash
npm run verify
npm run verify:browser
npm run cap:sync:ios
```

`verify`는 커밋 전 빠른 품질 게이트이고, `verify:browser`는 배포 전 모바일 브라우저 smoke 검증이다.
